# K. UI / UX Specification — 界面与体验规格

**日期**：2026-10-03 · 对应用户第十、二十四~二十六、二十九节

## K1. 设计原则

1. **一个入口**：打开就是 `Today`——Daily Brief 是产品的心脏，其他页面都是它的"证据仓库"。
2. **信任感 > 信息量**：每个数字可点开看来源；每个论断有五类标签；不可信的信息明确标灰。
3. **阅读优先**：brief 是"读"的不是"看仪表盘"的——排版按 newsletter 设计（Monarch/Copilot 的叙事体验 + Bloomberg 的密度）。
4. **永不催促**：没有红色涨跌警报式设计（涨绿跌红弱化）；机会卡片永远是"值得研究"而非"立即行动"。
5. **本地 web**：localhost 单用户；深色/浅色双主题；移动浏览器可用（响应式）以便躺床上看晨报。

## K2. 信息架构（6 页 + 全局抽屉）

```
Today ─ Portfolio ─ Feed ─ Learn ─ Research ─ Settings
└─ 全局: 搜索(Chat 入口) · 证据抽屉(右侧滑出) · 数据新鲜度指示器(右上角)
```

交互细节：
- 每条新闻/论断右侧 `[证据 N]` → 打开右侧**证据抽屉**：来源列表（Reuters 10-03 / Fed 官网 10-02 / X @xxx 10-03）、每源的 reliability 徽章、五类标签图例。
- `[▸ 计算明细]` → 净值计算式逐行展开（期初+流入-流出+市值变动=期末，含汇率）。
- 标签系统：`[事实]`蓝 `[市场预期]`紫 `[分析]`绿 `[观点]`橙 `[AI 推断]`灰虚线——图例常驻页脚。
- 底部固定反馈条：这条有用/没用 → 调 relevance 阈值与源权重（个性化飞轮）。

## K4. Portfolio

- 净值曲线（时间范围切换 1M/3M/1Y/ALL；**用历史汇率**，角标注明计价币）。
- 五维敞口（币种/国家/行业/资产类别/机构）可切换的堆叠条 + 表格（含 top10 单一标的、>10% 标红提示"集中度"）。
- 持仓表：账户分组、币种原值+本币值、成本/市值/盈亏、数据源与更新时间。
- What-if 面板（Should 级）：滑块"把 X% 现金移入短期债券" → 收益/波动/流动性三指标变化（全部代码计算，标注假设）。

## K5. Feed（新闻流）

- 默认"与我相关"排序（relevance），可切时间/来源。
- 每条卡片：五类标签、涉及实体芯片（`BoJ` `JPY` `利率`，点击看图路径——"这个实体如何连到我的账户"，Source Graph 可视化 ≤4 跳路径图）。
- 过滤器：只看 Fact / 只看持仓相关 / 按敞口维度。
- 事件聚合视图：`(NKE, FY2027Q1 earnings)` 下挂多源报道 + X 信号（若有）。

## K6. Learn（Wealth Academy）

- 首屏：今日课（未读则全屏进入阅读模式：概念→例子→与我的资产→小题）。
- 课程库：按域分组的概念 DAG 可视化（已完成●/学习中◐/未知○），点击任意概念可提前学。
- 进度：月度 IQ Check 入口 + "本月你学会了…"回顾。

## K7. Research（财报/深研存档）

- 持仓股财报 Brief 列表（最新置顶），brief 内 10 节锚点导航；
- 每节右侧"指标解释"悬浮（概念卡，联动知识图谱标记 learning）；
- 历史版本对比（本期 vs 上期核心指标，代码 diff）。

## K8. Chat（全局）

- 右下角常驻入口；回答强制结构：先结论 → 依据（含 `[计算]`/`[来源]` 徽章）→ 不确定处明说 → 追问建议。
- 涉及投资决策的回答自动套用 11 段输出契约（Situation→…→Questions For You），可折叠只看 Options 表。

## K9. Onboarding（首次体验，决定留存）

1. 选基础币种/地区/风险五问（2 分钟）；
2. 导入第一批数据（提供 IBKR Flex 下载指引截图 + CSV 拖拽）；
3. 选择关注源（预设包：宏观派/美股派/亚太派）；
4. 等待首份 brief 生成（进度条展示 Collect→Filter→…→Notify 八步动画——把架构可视化变成信任建立过程）。

## K10. 视觉基调

- 克制的金融排版：衬线标题（newsletter 感）+ 无衬线正文；主色一个（墨绿/藏蓝系），语义色仅用于标签与涨跌（弱化）。
- 图表：ECharts/Recharts，坐标轴/图例齐全（对齐 FinSight 的专业制图标准），AI 生成图必须过审计。
- 空状态/错误态都写成"人话"：如行情源失败显示"Yahoo 限流，已切换 Stooq（数据截至 10-01）"——诚实是本产品的 UI 原则。
