❓ 如何与我互动，实现财富的长期增值

  

    
☀️ 每日循环（5 分钟）

    1. 打开 Today 读晨报（数据自动更新）；2. 完成 Learn 今日一课并答题；
    3. 有疑问直接在底部对话框问（例：「我的现金占比多少」「日元为什么跌」）。

    
📅 每周循环（30 分钟）

    1. 读一篇 Research 研报精读（每周一自动更新观察名单）；2. 检视 Roadmap 进度；
    3. 看 Portfolio 是否出现新的「值得研究的机会」。

    
📈 增值路径（系统的设计逻辑）

    记录真实资产 → 建立备用金（Roadmap 1）→ 现金管理（Roadmap 3）→
    满足前提后小额定投宽基指数（Roadmap 4）→ 每年再平衡（Roadmap 5）。
    系统不替你做决定——它让你每个决定都有依据。

    
🔌 建议打通的接口（按优先级）

    · Telegram（免费，10 分钟）：配置 token 后晨报/研报自动推送到手机；

    · LLM Key：OpenAI/Anthropic 任一，解锁 AI 模式（自然语言简报与对话）；

    · 券商 API（开户后）：IBKR Flex Query / 长桥 / 老虎——持仓自动同步；

    · FRED Key（免费）：利率宏观数据增强；

    · X API（可选付费）：金融情报信号层。

    内地/香港银行暂无个人 API——用「导出 CSV → 拖入导入」覆盖。

    
所有数据只存在这台电脑上；上述 key 都只进本机，不上传任何服务器。
